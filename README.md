# Student Sahayak – Student Support Made Simple

## About the Project

**Student Sahayak** is a student-support website project designed to make educational information and useful student resources easier to discover and navigate.

The website aims to provide a simple interface for exploring scholarship resources, student-rights information, educational links, and project contact details.

## Objectives

- Make student-focused educational resources easier to find.
- Help students discover scholarship information and relevant portals.
- Provide access to student-rights guidance and useful resources.
- Offer a simple and user-friendly website experience.

## Website Sections

Depending on the features implemented in the project, the website may include:

- **Home:** Introduction to Student Sahayak.
- **Scholarships:** Links to scholarship resources.
- **Student Rights:** Student guidance and related information.
- **Help & Resources:** Useful educational links and resources.
- **About:** Information about the project.
- **Contact:** Project contact details.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/student-sahayak.git
   ```

2. Open the project folder:

   ```bash
   cd student-sahayak
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal, usually `http://localhost:5173`.

### Build for Production

Run the following command to create a production build:

```bash
npm run build
```

The generated production files are usually stored in the `dist` folder.
